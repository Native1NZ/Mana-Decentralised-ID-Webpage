Web3 Hackazthon based in UC Christchurch NZ
Authors: Nathan Bocock, Jesse Murphy,

For this program to run you need to download many python libraries. Such as PIL, pytesseract, web3, etc...
This project also needs a .env file to run specifically called ".env" this is to securely hold your APT key and
developer private key for your contract account. The deploy.py code needs to be run first to setup the contract so that it may be used
in the webpages.
